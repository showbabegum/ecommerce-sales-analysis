# E-commerce Sales Analysis

Python (pandas) analysis of e-commerce sales performance: revenue trends, seasonality, and regional and category breakdowns across 6,194 orders.

## What this project shows
- Revenue trends over time and seasonal patterns
- Regional and product-category breakdowns
- Data cleaning and exploratory analysis with pandas
